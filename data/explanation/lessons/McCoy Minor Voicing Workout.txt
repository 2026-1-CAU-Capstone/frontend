강의 출처 (Source): The Jazz Pursuit — "McCoy Minor Voicing Workout"

레벨 1: 범용 개념 설명 (Level 1: General Concepts)
1-1. 콰탈 보이싱이란 (What a Quartal Voicing Is)
instruction (KR): 맥코이 타이너 사운드의 핵심인 콰탈 보이싱이 뭐야?
instruction (EN): What is a quartal voicing, the core of the McCoy Tyner sound?

response (KR): 콰탈(quartal) 보이싱은 4도 음정을 쌓아 만든 코드입니다. 일반적인 코드가 3도를 쌓는 것과 달리, 4도 간격의 음을 모으는 것입니다. 이 워크아웃에서는 세 음이 모두 4도씩 떨어진 3음 스택을 목표로 합니다. 4도 쌓기는 3도 쌓기보다 모호하고 개방적인 사운드를 내며, 맥코이 타이너 특유의 강하고 현대적인 마이너 색채의 핵심입니다.
response (EN): A quartal voicing is a chord built by stacking fourths. Unlike ordinary chords that stack thirds, it gathers notes a fourth apart. In this workout the target is a three-note stack where all the notes are a fourth apart. Stacking fourths produces a more ambiguous, open sound than stacking thirds, and it's the heart of McCoy Tyner's strong, modern minor color.

1-2. 마이너 펜타토닉에서 콰탈 모양 찾기 (Finding Quartal Shapes in the Minor Pentatonic)
instruction (KR): 마이너 펜타토닉에서 콰탈 보이싱을 어떻게 만들어?
instruction (EN): How do I build quartal voicings from the minor pentatonic?

response (KR): C 마이너 펜타토닉(도리안의 1·♭3·4·5·♭7 = C-E♭-F-G-B♭)의 각 음에서 4도를 두 번 쌓아보며 펜타토닉 안에서만 음이 떨어지는지 확인합니다. 루트 C: C-F-B♭ (가능). ♭3 E♭: E♭-A♭…A♭이 펜타토닉에 없음 (불가). 4 F: F-B♭-E♭ (가능). 5 G: G-C-F (가능). ♭7 B♭: B♭-E♭-A♭…A♭ 없음 (불가). 따라서 마이너 펜타토닉에서는 루트·4도·5도 자리에서만 콰탈 모양이 만들어집니다.
response (EN): Take C minor pentatonic (the 1, ♭3, 4, 5, ♭7 of Dorian = C-E♭-F-G-B♭) and from each note try stacking two fourths, checking that the notes stay inside the pentatonic. From the root C: C-F-B♭ (works). From ♭3 E♭: E♭-A♭… there's no A♭ in the pentatonic (fails). From 4 F: F-B♭-E♭ (works). From 5 G: G-C-F (works). From ♭7 B♭: B♭-E♭-A♭… no A♭ (fails). So in the minor pentatonic, quartal shapes are only buildable off the root, the 4th, and the 5th.

1-3. 패럴렐 셰이프와 맥코이 사운드 (Parallel Shapes and the McCoy Sound)
instruction (KR): 그 콰탈 모양들을 어떻게 써야 맥코이다운 소리가 나?
instruction (EN): How do I use those quartal shapes to get the McCoy sound?

response (KR): 진짜 맥코이 사운드를 내려면 패럴렐(평행) 셰이프, 즉 같은 모양을 평행 이동시키는 것이 핵심입니다. 그래서 루트 자리는 빼고, 4도와 5도에서 만든 두 콰탈 셰이프를 평행하게 사용합니다. 이 오른손 콰탈 셰이프들을 받쳐주기 위해 왼손에는 루트와 5도를 둡니다. 이렇게 하면 4도 쌓기의 개방적 울림과 평행 이동의 강한 추진력이 결합되어 맥코이 특유의 마이너 컴핑이 됩니다.
response (EN): For the true McCoy sound, the key is parallel shapes — moving the same shape in parallel. So leave out the root position and use the two quartal shapes built off the 4th and the 5th in parallel. To support these right-hand quartal shapes, place the root and 5th in the left hand. This combines the open ring of stacked fourths with the strong momentum of parallel motion to produce McCoy's signature minor comping.

레벨 2: 워크아웃 구성 (Level 2: The Workout Itself)
2-1. 컴핑 패턴과 5도권 순환 (The Comping Pattern and the Cycle of Fourths)
instruction (KR): 이 워크아웃은 구체적으로 어떻게 진행돼?
instruction (EN): How does the workout actually proceed?

response (KR): 컴핑 패턴 자체는 2마디 길이입니다. 이것을 각 키에서 4번 반복하므로 한 코드(마이너 키)에 8마디를 머뭅니다. 그다음 4도 위(=5도권을 따라)로 올라가 다음 마이너 키로 넘어갑니다. C 마이너 → F 마이너 → B♭ 마이너 → E♭ 마이너 → A♭ 마이너 … 이렇게 한 바퀴 돌아 다시 C 마이너로 돌아옵니다. 각 키의 마이너 펜타토닉을 기준으로 같은 콰탈/평행 셰이프를 적용하면 됩니다.
response (EN): The comping pattern itself is two bars long. You play it four times in each key, so you stay on each chord (minor key) for eight bars. Then you move up a fourth (around the cycle of fourths) to the next minor key: C minor → F minor → B♭ minor → E♭ minor → A♭ minor … all the way around and back to C minor. In each key, apply the same quartal/parallel shapes based on that key's minor pentatonic.

2-2. 난이도 올리기 (Increasing the Difficulty)
instruction (KR): 익숙해지면 어떻게 강도를 높여?
instruction (EN): Once I'm comfortable, how do I make it harder?

response (KR): 처음에는 각 코드에 8마디(패턴 4회)를 머물며 여유 있게 연습합니다. 익숙해지면 각 코드에 4마디(패턴 2회)만 머무는 더 빠른 버전으로 넘어가, 코드 전환과 평행 셰이프 이동을 두 배 빠르게 처리하도록 도전합니다. 백킹 트랙 속도를 올리거나 키 전환을 더 촘촘히 하는 것도 좋은 방법입니다.
response (EN): Start by staying on each chord for eight bars (the pattern four times) for relaxed practice. Once comfortable, move to a faster version that sits on each chord for only four bars (the pattern twice), challenging yourself to handle the chord changes and parallel-shape moves twice as fast. Raising the backing-track tempo or shortening the key changes are also good ways to push it.

레벨 3: 연주 판단 (Level 3: Performance Decisions)
3-1. 콰탈 보이싱을 실전 컴핑에 쓰기 (Using Quartal Voicings in Real Comping)
instruction (KR): 이 콰탈 보이싱들을 실제 곡 컴핑에서 어떻게 활용해?
instruction (EN): How do I use these quartal voicings when comping on a real tune?

response (KR): 모달하거나 마이너 펜타토닉으로 길게 머무는 곡(예: 마이너 모달 곡, So What 류, 또는 마이너 i 코드가 오래 지속되는 구간)에서 특히 잘 맞습니다. 한 마이너 영역에 머무는 동안 4도와 5도에서 만든 콰탈 셰이프를 평행하게 위아래로 움직이면, 3도 보이싱보다 덜 기능적이고 더 개방적인 텍스처가 만들어져 솔로이스트에게 넓은 공간을 줍니다. 왼손 루트·5도가 베이스를 잡아주므로 코드의 정체성은 유지됩니다.
response (EN): They fit especially well on modal tunes or passages that sit on a minor pentatonic for a long time (e.g. minor modal tunes, "So What"–type vamps, or sections where a minor i chord is sustained). While you stay in one minor area, moving the quartal shapes built off the 4th and 5th in parallel up and down creates a less functional, more open texture than third-based voicings, giving the soloist lots of space. The left-hand root and 5th anchor the bass so the chord's identity stays clear.

3-2. 마이너 펜타토닉과 콰탈의 관계 이해하기 (Understanding the Pentatonic–Quartal Link)
instruction (KR): 왜 하필 마이너 펜타토닉에서 콰탈 보이싱을 뽑아내는 거야?
instruction (EN): Why specifically derive the quartal voicings from the minor pentatonic?

response (KR): 마이너 펜타토닉은 마이너/도리안 사운드의 가장 안전하고 핵심적인 음들(1·♭3·4·5·♭7)만 모은 스케일이라, 여기서 뽑은 콰탈 셰이프는 어떤 마이너 컨텍스트에도 충돌 없이 들어맞습니다. 또한 펜타토닉 안에서만 4도를 쌓으면 비교적 적은 위치(루트·4·5)에서만 깔끔한 콰탈이 나오는데, 그 제약 덕분에 손에 외울 모양이 적고 평행 이동이 쉬워 즉흥 컴핑에서 빠르게 꺼내 쓸 수 있습니다.
response (EN): The minor pentatonic gathers only the safest, most essential notes of the minor/Dorian sound (1, ♭3, 4, 5, ♭7), so quartal shapes drawn from it fit any minor context without clashing. Also, stacking fourths only within the pentatonic yields clean quartals at just a few positions (root, 4th, 5th); that constraint means fewer shapes to memorize and easy parallel motion, so you can reach for them quickly in live comping.
