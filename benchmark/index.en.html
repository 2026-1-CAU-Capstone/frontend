● Neuro-Symbolic + RAG Ablation Benchmark

NSR-Bench
What does each layer add?

A benchmark that quantitatively decomposes — under identical conditions — how much each augmentation layer (a symbolic rule engine and domain retrieval / RAG) contributes when stacked onto an LLM, in the jazz-harmony pedagogy domain.

A · Raw LLM→ B · +Rule→ C · +Rule +RAG same question / model / gold — only the layer changes

What it compares

Three augmentation layers

Existing music-LLM benchmarks ask “how well does the model do task X?” (a leaderboard). NSR-Bench asks “what does each layer contribute?” (a decomposition). A→B difference = the Rule layer's marginal contribution; B→C = RAG's.

A · BASELINE

Raw LLM

Model alone. The corpus's song-specific knowledge is absent from its parametric memory.

reference point
B · SYMBOLIC

+ Rule Engine

Injects deterministic harmonic analysis (key, function, ii-V-I) as authoritative context.

+ accuracy · consistency
C · NEURAL RETRIEVAL

+ RAG

Retrieves from the domain corpus (1,376 teacher-analysis chunks) and injects it into the answer.

+ explanation depth · grounding
Two axes: layer (A/B/C) × model scale — Haiku 4.5 (small) vs Sonnet 4.6 (large) · Judge Sonnet 4.6 · temp 0

Design controls

circularity defense
  1. Same question/model/gold, only the layer changes → controlled ablation
  2. F questions paraphrased → breaks lexical match with chunks
  3. corpusOnly=false control subset (bias check)
  4. provenance embedded → enables retrieval ablation
  5. A·G gold is corpus-independent → immune to circularity
Honest limitation (state it first): F·E gold is derived from the corpus, so the measured RAG gain is an in-distribution upper bound, not a real-world estimate. The direction (surfacing domain knowledge the base model lacks) is validated by raw's low scores, but the magnitude is corrected via retrieval ablation (swap the correct chunk for a random one). Rule contributions (A·G) are free of this issue — their gold is corpus-independent.
