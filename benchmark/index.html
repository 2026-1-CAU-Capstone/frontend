● Neuro-Symbolic + RAG Ablation Benchmark

NSR-Bench
레이어가 무엇을 더하는가

재즈 화성 교육 도메인에서, LLM에 심볼릭 룰 엔진과 도메인 검색(RAG)을 단계적으로 얹었을 때 각 레이어가 어떤 능력을 얼마나 더하는지를 같은 조건에서 정량 분해하는 ablation 벤치마크.

A · Raw LLM→ B · +Rule→ C · +Rule +RAG 동일 질문·모델·정답, 레이어만 교체

무엇을 비교하나

세 개의 증강 레이어

기존 음악 LLM 벤치마크가 “모델이 태스크 X를 얼마나 잘하나”(리더보드형)를 묻는다면, NSR-Bench는 “각 레이어가 무엇을 기여하나”(기여 분해형)를 묻는다. A→B 차이 = Rule의 순기여, B→C 차이 = RAG의 순기여.

A · BASELINE

Raw LLM

모델 단독. 도메인 코퍼스의 곡-특유 지식은 파라메트릭 메모리에 없다.

Rule = 신뢰성 레이어(정확성·일관성) · RAG = 지능 레이어(설명 깊이·근거). 각자 다른 능력을 책임지며, 둘 다 있어야 완성된다.

설계 통제

순환성 방어
  1. 동일 질문·모델·정답, 레이어만 변경 → 통제된 ablation
  2. F 질문 패러프레이즈 → 청크 어휘 매칭 차단
  3. corpusOnly=false 대조군 8개 (편향 점검)
  4. provenance 내장 → retrieval ablation 가능
  5. A·G는 코퍼스 무관 골드 → 순환성 면역
정직한 한계 (발표에 먼저 명시): F·E는 골드가 코퍼스에서 파생되어, 측정된 RAG 상승은 현실값이 아니라 in-distribution 상한이다. 방향(베이스에 없는 도메인 지식 surfacing)은 raw의 낮은 점수로 검증되지만, 크기는 retrieval ablation(정답 청크↔랜덤 청크 교체)으로 보정한다. Rule 기여(A·G)는 골드가 코퍼스와 무관해 이 문제에서 자유롭다.
